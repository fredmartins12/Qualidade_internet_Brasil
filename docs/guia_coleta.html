1. O que é essa etapa do trabalho

Para analisar a qualidade da nossa conexão de internet, precisamos de dados próprios — não só dos relatórios públicos (SIMET/Anatel). Para isso, montamos um script em Python que envia pacotes de rede para servidores conhecidos (Google e Cloudflare) e mede três coisas:

MétricaO que significa
Latência (RTT)Tempo de ida e volta de um pacote até o servidor, em milissegundos. Quanto menor, melhor.
Desvio-padrão (stdev)Dispersão do RTT em torno da média — a métrica clássica usada pelo ping do sistema operacional.
JitterVariação da latência entre um pacote e outro. Jitter alto = conexão instável, ruim para videochamada/jogos.
Perda de pacotesPercentual de pacotes que não voltaram (se perderam no caminho). Indica congestionamento ou falha na rede.
Base teórica: esse script é uma extensão do ICMP Pinger Lab (um dos trabalhos de programação oficiais do livro-texto Kurose & Ross, capítulo de ICMP). O lab original pede para montar o pacote ICMP manualmente com socket raw; aqui usamos a biblioteca Scapy para fazer a mesma coisa de forma mais robusta, o que permite escalar a coleta (vários alvos, agendamento, milhares de amostras) em vez de reimplementar o protocolo byte a byte.

Essa coleta precisa rodar várias vezes ao longo do dia (de preferência por vários dias), para capturarmos como a qualidade da conexão muda em horários diferentes — por exemplo, se piora no "horário de pico" (19h–22h). É esse histórico que depois vamos analisar e comparar com os dados do SIMET.

Resumindo para quem não mexe muito com código: cada pessoa do grupo que puder vai deixar um probleminha (script) rodando no próprio computador em segundo plano, a cada 15 minutos, por alguns dias. Ele só gera um arquivo .csv (uma planilha) com números — não acessa nada pessoal, não precisa ficar de olho nele.

2. Pré-requisitos (fazer uma vez só)

  1. Ter o Python 3.11+ instalado (python.org/downloads). Durante a instalação, marcar a caixa "Add Python to PATH".
  2. Instalar o Npcap: npcap.com/#download. Durante a instalação, marcar a opção "Install Npcap in WinPcap API-compatible Mode". (É o driver que permite o script enviar pacotes de rede diretamente.)
  3. Abrir o terminal (PowerShell) como Administrador: clique direito no ícone → "Executar como administrador".
  4. Navegar até a pasta do projeto e instalar as dependências: 
    cd "C:\caminho\para\reds"
pip install -r requirements.txt

3. Testar a coleta manualmente

python coleta\probe.py --targets 8.8.8.8 1.1.1.1 --count 20

Se der certo, aparece uma linha no terminal por alvo (média de RTT, jitter, perda) e é criado o arquivo dados\probes.csv.

Atenção: o terminal precisa estar aberto como Administrador. Sem isso, o Scapy não consegue enviar os pacotes (erro de permissão) — é a causa mais comum de problema aqui.

4. Deixar a coleta rodando sozinha (Agendador de Tarefas)

Para não precisar rodar manualmente toda hora, usamos o Agendador de Tarefas do Windows:

  1. Abrir Agendador de Tarefas (pesquisar no menu Iniciar).
  2. Clicar em "Criar Tarefa..." (não "Tarefa Básica").
  3. Na aba Geral: dar um nome (ex: "Coleta Redes") e marcar "Executar com privilégios mais altos".
  4. Na aba Disparadores: Novo → Diariamente → repetir a tarefa a cada 15 minutos, por uma duração de 1 dia (assim ela repete indefinidamente).
  5. Na aba Ações: Novo → Programa/script → selecionar o arquivo coleta\run_probe.bat (já está pronto na pasta do projeto).
  6. Salvar. O Windows vai pedir a senha da sua conta (necessário para rodar com privilégio elevado mesmo com a tela bloqueada).

5. O que fazer com os dados depois

Depois de alguns dias de coleta, cada pessoa envia o arquivo dados\probes.csv gerado no seu computador para o grupo (pode ser pelo WhatsApp/Drive mesmo). Com isso juntamos as coletas de diferentes locais/redes e rodamos o script de agregação (analise\aggregate.py), que organiza tudo por hora do dia — preparando para a etapa de análise e machine learning.
